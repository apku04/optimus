CASCaded PI Controller (Fresh Implementation)
===========================================

What this is
------------
This repo previously experimented with a position-step decoupled controller.
If you still see hunting/oscillation ("chasing"), a more standard control
architecture for camera-on-gimbal tracking is a cascaded loop:

  image error -> desired image velocity (PI)
  desired image velocity -> motor angular rates using calibration A
  motor rates -> integrated into short position segments (Klipper MANUAL_STEPPER)

This produces continuous motion (gimbal-like) without needing to pause/settle.

How to run
----------
On the Raspberry Pi:

  cd /home/acp/optimus
  python3 rpi/head_tracker_cascaded.py

Dry-run (no motors):

  python3 rpi/head_tracker_cascaded.py --dry-run

Requirements
------------
This controller uses the calibration matrix in config.json:
  tracking_decoupled.dx_dpan
  tracking_decoupled.dx_dtilt
  tracking_decoupled.dy_dpan
  tracking_decoupled.dy_dtilt

If those are missing, run:

  python3 rpi/head_tracker_decoupled.py --calibrate

Tuning knobs (config.json)
--------------------------
Add an optional section:

  "tracking_cascaded": {
    "loop_hz": 60,
    "segment_dt_s": 0.05,
    "queue_limit_s": 0.25,

    "deadzone": 0.11,
    "min_confidence": 0.40,
    "meas_ema": 0.80,

    "kp": 1.10,
    "ki": 0.35,
    "integral_limit": 0.80,

    "delay_comp_s": 0.06,

    "max_pan_rate_dps": 90,
    "max_tilt_rate_dps": 65,
    "max_pan_accel_dps2": 600,
    "max_tilt_accel_dps2": 450,

    "combine_moves": true
  }

Meaning:
- kp/ki: image-domain PI gains. If it oscillates, reduce kp first.
- delay_comp_s: compensates measurement+actuation delay; too big can destabilize.
- max_*_rate_dps: caps the commanded motor rates.
- max_*_accel_dps2: limits how quickly rate can change (smoothness + stability).
- segment_dt_s + queue_limit_s: determines how frequently we send short segments.

Operational tip
---------------
Start conservative:
- set kp low enough that it does NOT overshoot when the face is stationary.
- increase max_accel slowly until motion feels smooth.

If you see "micro-hunting" near center, increase deadzone or meas_ema.
